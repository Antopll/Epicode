# Esercitazione finale

Progetto di sintesi del modulo **M2 – Statistica & Excel**: applica su dataset reali
gli argomenti visti nelle quattro settimane (statistica descrittiva e inferenziale,
test A/B, Excel avanzato, Power Query, Power Pivot).

## 📁 Come sono organizzati i file

Ogni file `.xlsx` raccoglie **3 esercizi**, uno per foglio di lavoro.
All'interno di ciascun foglio trovi:

- lo **svolgimento**, con le formule effettivamente usate;
- una **breve spiegazione del ragionamento** che ho seguito — perché ho scelto
  quella funzione e come ho interpretato il risultato.

## 🎨 Legenda colori

Per rendere i fogli leggibili a colpo d'occhio ho usato una codifica cromatica costante:

| Colore | Significato |
|---|---|
| 🟡 Giallo | Celle di **intestazione** |
| 🟢 Verde | Celle che contengono le **formule/funzioni** applicate |

> Le celle non colorate contengono dati di input o risultati intermedi digitati manualmente.
> Lo schema è rispettato nella maggior parte dei fogli;
